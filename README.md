## 🚀 Features

- 📝 **Create & Manage Pages** — Create multiple notebook pages and move between them easily.
- 💾 **Persistent Local Storage** — Automatically save notebook data and keep it available after refreshing the page.
- 🧠 **Structured JavaScript Architecture** — Organized functions handle page creation, rendering, saving, loading, and application state.
- 🎨 **Customizable Paper Styles** — Choose between different notebook styles for a personalized writing experience.
- 📅 **Automatic Date & Time** — Each page receives its date automatically, with save times displayed when changes are stored.
- 🔢 **Smart Page Counters** — Track the current page and total number of pages dynamically.
- 📊 **Live Content Counters** — Keep track of the content written inside each notebook page.
- 💾 **Save Status Feedback** — Clearly shows whether a page has been saved and displays the latest save time.
- 📱 **Responsive Design** — Designed to provide a clean and usable experience across desktop and mobile screens.
- ⚡ **Interactive User Experience** — Dynamic interface updates without reloading the page.
